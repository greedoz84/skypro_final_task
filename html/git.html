Git

  • git init — создаёт новый локальный репозиторий в текущей папке.
  • git clone — копирует существующий удалённый репозиторий на ваш компьютер.
  • git status — показывает состояние файлов в рабочем каталоге (изменённые, новые, подготовленные к коммиту).
  • git add <файл> — добавляет файлы в индекс (staging area) для подготовки к сохранению.
  • git commit -m "сообщение" — сохраняет проиндексированные изменения в историю репозитория.
  • git diff — показывает разницу между файлами в рабочей директории и индексом
  • git branch — выводит список локальных веток.
  • git switch -c <ветка> — создаёт новую ветку и сразу переключается на неё.
  • git merge <ветка> — объединяет изменения из указанной ветки в текущую.
  • git remote -v — показывает список подключенных удалённых репозиториев.
  • git fetch — скачивает последние изменения с удалённого сервера без их слияния с вашим кодом.
  • git pull — скачивает изменения с удалённого сервера и сразу объединяет их с текущей веткой.
  • git push — отправляет ваши локальные коммиты на удалённый репозиторий.
  • git log — выводит историю коммитов.
  • git checkout <файл> или git restore <файл> — отменяет изменения в файле до состояния последнего коммита.
  • git reset <коммит> — откатывает состояние репозитория назад.
